#  Sito Pratico TPSIT Film

Progetto scolastico realizzato per la materia TPSIT.

##  Descrizione

Questo sito permette di gestire una lista di film tramite JavaScript.

L'utente può:

* aggiungere film
* visualizzare la lista
* eliminare film
* salvare i dati nel LocalStorage

##  Tecnologie utilizzate

* HTML
* CSS
* JavaScript

##  Come avviare il progetto

1. Scaricare o clonare la repository
2. Aprire il file `index.html` nel browser

##  Struttura progetto

* `index.html` → struttura del sito
* `style.css` → grafica
* `script.js` → logica JavaScript
